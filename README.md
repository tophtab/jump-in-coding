# Jump in Coding

一个自动触发的 Codex skill，用来让 AI 在生成代码、调试、评审和回应时，顺手解释相关的编程概念、技术概念和工程取舍。

## 它做什么

- 在 AI 写代码时，解释当前实现背后的关键概念。
- 在 AI 分析错误、日志或测试结果时，说明问题属于哪类技术问题。
- 在 AI 做工程判断时，补充为什么这样选，而不是只给结论。
- 保持任务推进优先，概念解释保持简短、贴近当前代码。

## 怎么触发

这个 skill 主要作为自动增强层使用。启用后，用户可以直接提出普通开发任务，AI 会在合适的时候补充相关概念说明。

## 文件结构

```text
.
├── SKILL.md            # skill 的主要行为说明
└── agents/openai.yaml  # 展示名、简介和默认提示词配置
```

## 风格

默认使用用户的语言。解释不抢主线，不把每一步都变成课程，只在当前代码、错误或工程取舍需要时补充有用的上下文。
